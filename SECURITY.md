# Security policy

This plugin handles authentication. Please do not open public issues for vulnerabilities.

Report privately through GitHub: **Security → Report a vulnerability** on this repository. Include the version or
commit, the setup (WordPress, FireFly and verifier versions), and steps to reproduce.

We aim to acknowledge reports within three working days and to agree a disclosure date with you.

The threat model is in [docs/SECURITY-MODEL.md](docs/SECURITY-MODEL.md). Reports that show a way around one of its
mitigations are especially welcome.

## Supported versions

The project is pre-1.0. Only the latest commit on `main` receives fixes.
